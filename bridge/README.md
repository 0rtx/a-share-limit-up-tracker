# 通达信数据桥接服务（TDX Bridge）

为「A股涨停跟踪」页面提供**本地通达信数据源**：涨停/炸板/跌停池、连板与涨停统计、
行业/概念板块、强势股池，全部由通达信官方数据本地计算；仅盘中实时刷价与封板时间
使用腾讯公开行情（通达信没有网页实时接口，详见下方「数据来源」）。

## 快速开始

1. 双击 `run_bridge.bat`（保持窗口开着即服务运行）。
   - 需要 Python 3.8+（脚本会自动找系统 Python；找不到会用 DSH 自带 Python）。
   - 手机/平板等其它设备也想用时，用 `run_lan.bat` 并放行防火墙。
2. 打开页面 `https://0rtx.github.io/a-share-limit-up-tracker/`，右上角把
   「数据源」从**云端数据**切换为**本地通达信**。
3. 服务地址 `http://127.0.0.1:8770`，健康检查 `http://127.0.0.1:8770/api/ping`。

服务没开时，页面会自动回退到云端数据源（东方财富/新浪）并提示。

## 数据来源（重要）

| 数据 | 来源 |
|------|------|
| 全市场日线、涨停/炸板/跌停判定、连板数、涨停统计、60日新高 | 通达信官网每日盘后包 g4day（最新交易日）+ 通达信客户端本地 vipdoc `*.day` 日线 |
| 行业板块（110个） | 通达信客户端本地 `tdxhy.cfg` + `tdxzs.cfg` |
| 概念板块（268个） | 通达信客户端本地 `infoharbor_block.dat` |
| 封板时间/最后封板/炸板次数 | 腾讯逐笔成交（3秒粒度，仅最新交易日；后台异步采集，约1分钟补齐） |
| 盘中实时价格/换手率/量比/涨速/封单 | 腾讯行情快照（交易时段每60秒刷新） |

### 已知限制（请务必了解）

- **Level-2 普及版会员数据无法用于网页**：L2（十档、逐笔委托）只在通达信客户端内
  加密下发，没有网页/接口方式可取，本桥接也不使用。
- **地域板块暂不支持**：通达信本地文件里没有地域板块成分，TDX 模式下该页签已隐藏。
- **封板时间只有最新交易日**有（腾讯逐笔只有当日），历史日期显示「—」。
- 历史日期第一次打开需要读全市场本地日线（约 10~20 秒），之后有缓存就快了。
- 涨停池口径与东财一致：剔除 ST 与新股；炸板 = 当日曾封住涨停但收盘未封住。
- 数据时效依赖：通达信客户端需定期「盘后数据下载」（vipdoc 日线）；官网盘后包
  由本服务自动下载补齐最新交易日（收盘后数小时发布）。

## 接口

- `GET /api/ping` — 状态
- `GET /api/pools?date=YYYYMMDD` — 涨停/炸板/跌停池（date 缺省或 20991231 = 最新）
- `GET /api/boards?type=2|3&date=` — 行业(2)/概念(3) 板块
- `GET /api/strong?date=` — 强势股池
- `GET /api/calendar?date=&dir=-1|1` — 上/下一交易日

## 命令行参数

```
python tdx_bridge.py --host 127.0.0.1 --port 8770 --tdx-dir D:\new_tdx64
```
